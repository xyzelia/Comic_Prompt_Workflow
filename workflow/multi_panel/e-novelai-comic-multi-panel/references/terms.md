# 多 Panel 术语表模板

`terms.md` 锁定跨 Page、Panel 和 Prompt 重复使用的人名、地点、道具及布局定位。Storyboard 可以使用用户工作语言，最终 Prompt 必须复用锁定值。

```markdown
# Terms — [漫画标题]

## Characters
| Source | Prompt value |
|---|---|
| 林 | Lin |

## Locations
| Source | Prompt value |
|---|---|
| 天台 | rooftop |

## Props
| Source | Prompt value |
|---|---|
| 黄色外套 | mustard yellow hooded jacket |

## Panel Positions
| Storyboard label | Prompt phrase |
|---|---|
| 左上格 | top-left panel |
| 右上格 | top-right panel |
| 底部宽格 | wide bottom panel |

## Text Types
| Storyboard label | Prompt phrase |
|---|---|
| 对白气泡 | speech bubble |
| 旁白框 | caption box |
```

规则：

- 第一次使用前登记；不临时创造名称变体。
- 同一 Panel 定位在 Layout、Storyboard 和所有 Character Prompt 中使用相同短语。
- Outfit 和饰品如已登记，应与人物资料 Prompt 一致。
- 修改锁定值时，备份并更新所有受影响页面记录。
- 通用动作、表情、镜头和光线不必全部登记；只有会重复且容易漂移的词才加入。
